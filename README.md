<h1>Site Quase Tudo Gostoso </h1>
 
<h3>Instruções para funcionamento correto da aplicação web:</h3>
 
<ol>
    <li>Garantir que tenha instalado o VS Code na maquina e esteja instalado a estensão "Live Server".</li>
    <li>Garantir que todos os arquivos e pastas foram baixados corretamente(assets, server, admin.html, cadastro.html, index.html, LICENCE, login.html, quase-tudo-gostoso-database.sql).</li>
    <li>Garantir que o XAMPP está instalado e ativado.</li>
    <li>Garantir que o node.js foi instalado e configurado no computador.</li>
    <li>Garantir que o banco de dados "quasetudogostoso" foi criado no Workbench MySQL, a partir do script quase-tudo-gostoso-database.sql.</li>
    <li>No VS Code, abra o terminal na pasta "servidor" e digite o comando: 

```bash
npm install
```
para instalar todos os pacotes adcionais do Node.
</li>
    <li>Após a intalação de todos os pacotes, escrever o comando: 

```bash
node server.js
```
no mesmo terminal, para iniciar o servidor.</li>
    <li>Assim o sistema estará pronto para funcionar.</li>
</ol>
