<h1>Site Quase Tudo Gostoso </h1>
 
<h3>Instruções:</h3>
 
<ol>
    <li>Garantir que tenha instalado o vscode na maquina e esteja instalado a estensão do Live Server.</li>
    <li>Garantir que todos os arquivos e pastas foram baixados corretamente(assets, server, admin.html, cadastro.html, index.html, LICENCE, login.html, quase-tudo-gostoso.sql).</li>
    <li>Garantir que o XAMPP está instalado e ativado.</li>
    <li>Garantir que o node.js foi instalado e configurado no computador.</li>
    <li>Garantir que o banco de dados "quasetudogostoso" foi criado no workbenchmsql, a partir do script quase-tudo-gostoso.sql.</li>
    <li>Abrir o terminal na pasta "servidor" e digitar o seguinte comando: "npm install", para instalar todos os pacotes adcionais.</li>
    <li>Após a intalação de todos os pacotes, escrever o comando "node server.js" no mesmo terminal, para iniciar o servidor.</li>
    <li>Assim o sistema estará pronto para funcionar.</li>
</ol>
